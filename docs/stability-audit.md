# v0.3.16 안정성 점검

중단된 Claude 세션 `21521021-2acc-4b5c-a78b-ee029d1a3c02`의 점검과 미커밋 수정에서 이어서 작업했다. v0.3.15 Git 그래프를 유지하면서 아래 문제를 수정했다.

## 요청·콘텐츠 격리

- HTTP와 WebSocket 모두 Host·Origin·Sec-Fetch-Site 검사. 외부 사이트, opaque origin, DNS rebinding 요청 차단. Vite 출처는 개발 서버에서만 허용한다.
- JSON 변경 요청의 Content-Type 검사, 첨부 요청 32 MiB 제한, WebSocket 프레임 상한.
- Markdown raw HTML을 파싱한 뒤 sanitize하고 하이라이트한다. 기본 서식·이미지·줄바꿈은 유지하고 iframe·object·base·form·meta·스크립트·이벤트 속성은 제거한다.
- 외부 Markdown 이미지는 클릭해야 불러온다. 로컬 파일 링크는 앱 미리보기로 연결하며 raw 문서 URL을 href에 노출하지 않는다.
- raw HTML·SVG 응답 sandbox와 nosniff, 앱 HTML의 CSP, Electron renderer sandbox·외부 스킴 제한·앱 외 이동 차단·IPC 발신 프레임 검사.
- 휴지통·터미널 AppleScript는 파일 경로를 argv로 받아 문자열·셸 인젝션을 막는다. 사용하지 않던 임의 command 파라미터 제거.

## 세션·파일·설정

- 시작 요청 ID로 동시 세션·히스토리를 매칭한다. 시작 실패는 해당 Promise를 거절하며 초기 이벤트보다 session.started를 먼저 보낸다.
- seq 0 명령 오류도 표시한다. 전송 실패는 pending·경과 시간을 해제하고, 권한 변경 오류는 실제 실행 중인 턴 상태를 유지한다.
- 재연결 때 attach를 먼저 보내고 대기 명령을 전송한다. 닫힌 세션은 업데이트를 막지 않으며 이후 정리한다. 종료 중 새 세션·PTY 생성도 차단한다.
- Claude 권한 모드 재실행 중 전송은 기다린다. 종료·재실행의 interrupt 대기만 제한하며, AI 작업 시간 자체에는 상한을 추가하지 않았다.
- Codex 메시지 형식 오류·stdin EPIPE, 잘못된 WebSocket/PTY 프레임이 서버 전체를 종료시키지 않도록 처리했다.
- 설정 read/modify/write를 직렬화하고 임시 파일 rename으로 저장한다. 깨진 설정은 기본값으로 덮어쓰지 않고 오류를 반환한다.
- 첨부 이름은 UUID를 사용한다. 히스토리에 이미지·파일이 섞인 메시지도 첨부를 모두 복원한다.
- 특수 파일 읽기, 폴더명 경로 이탈, 같은 폴더로 이동할 때 이름이 바뀌는 문제, 미디어 Range 끝 범위를 수정했다. EXDEV만 복사·삭제 이동으로 처리한다.
- Git의 fsmonitor·외부 diff 실행을 막고 빈 reset·옵션 형태 브랜치를 거부한다. clean tracked diff를 신규 파일로 잘못 표시하지 않는다.
- 아이콘은 프로젝트 안의 실제 이미지 파일만 허용하며 symlink 이탈을 차단한다. 변환 캐시 키 충돌을 제거한다.
- 사용량 조회가 Codex refresh token을 회전하거나 CLI 로그인 파일을 덮어쓰지 않는다. 만료 시 CLI 로그인 갱신을 안내한다.

## 화면·업데이트·설치

- 프로젝트·파일·검색·히스토리를 바꾼 뒤 늦게 도착한 응답을 무시한다. Git 추가 로딩 중 목록 교체도 세대로 구분한다.
- Git 새 브랜치 입력을 Electron이 지원하지 않는 prompt 대신 인라인 폼으로 제공한다. 중복 커밋·작업 중 원격 조작을 막고 실패를 표시한다.
- 세션별 Composer, IME 확정 처리, 첨부 실패 표시, 파일 브라우저 ⌘↑/⌘↓, Agent 뷰 ⌘W, 짧은 채팅의 자동 스크롤을 수정했다.
- 업데이트 SSE 연결 끊김·재시작 확인 시간 초과 시 오류를 표시하고 모달 잠금을 해제한다. 잠긴 동안 전역 단축키로 업데이트 UI가 사라지지 않는다.
- 업데이트 체크는 동시에 하나만 실행한다. 적용 중에는 추가 fetch를 막는다.
- 업데이트는 같은 파일시스템의 staging 디렉터리에서 clone·설치·빌드한다. 선택한 정확한 커밋을 반영하고, 실패하면 교체한 세 빌드 폴더를 복원한다.
- 설치는 앱 종료를 기다리고 완성·서명한 번들로 교체한다. 런처는 경로를 JSON으로 기록하고 체크아웃을 못 찾으면 복구 안내를 표시한다. Node 다운로드 체크섬 확인, npm ci, 설치 위치 보관, Intel spawn-helper 권한도 적용했다.
- Electron 단일 인스턴스, 종료 중 재시작 타이머 취소, 연결한 외부 서버 감시, 빌드·체크아웃 일치 확인을 추가했다.

## 검증과 한계

- `npm test`: 18개 테스트. 실제 임시 Git 저장소로 분기·병합·페이지, 악성 설정, 업데이트 성공·빌드 실패·로컬 충돌을 확인한다.
- `npm run test:ui`: 숨겨진 Electron 창과 임시 프로필에서 프로젝트/diff 응답 경합, 새 브랜치, 중복 커밋, Markdown, 업데이트 연결 끊김·재시작 시간 초과를 확인한다.
- `npm run typecheck`, `npm run build`, 설치·업데이트 셸 구문 검사를 수행한다. 번들 크기 경고는 남아 있다.
- 실제 로그인한 AI의 유료 턴, 실제 앱 재설치·제거, 로그인 자동 실행, 강제 종료·디스크 고갈 상황은 실행하지 않았다. 이 검증은 실제 사용자 세션과 설치본을 변경하지 않는다.
- Electron 버전 변경은 실행 중인 바이너리를 교체하지 않고 `scripts/update.sh` 경로로 재설치한다. macOS 설치·서명·로그인 실행은 실제 설치 환경에서 별도 확인이 필요하다.
- 첨부 파일은 과거 대화에서 계속 참조하므로 임의 TTL 삭제를 추가하지 않았다. 보관 공간 관리와 대규모 대화의 전체 히스토리 복원은 별도 개선 항목이다.
